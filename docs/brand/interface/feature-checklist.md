# Workstation redesign acceptance checklist

Reviewed against the running Vue dashboard on November 11, 2026. The repeatable browser checks use disposable data, controlled model replies and synthetic audio. The desktop and touch inspection used locally recorded Yahoo candles. [Browser results](../../screenshots/indicators-signals/report.json) · [Verification log](../../verification.md#indicators-and-signals-workspace).

- [x] Chart — live candles and aligned volume at 1m, 5m, 15m, 30m, 1hr, D, W and M. Inspect timestamp, OHLC, reported or unknown volume, forming/ended state and coverage. Feed details contains the chart attribution, health check, transport and timestamps. Source, age and status are visible below the chart.
- [x] Replay — choose saved symbol and receipt-time range, restart, step one observation, play/pause, inspect progress and source/receipt times. Preserve recorded order, corrections and separate replay account behavior.
- [x] Indicators — toggle six SMA and six EMA presets, create named SMA, EMA and rolling ranges, edit and persist windows, inspect values and the separate range pane. Warm-up and forming candles have gaps.
- [x] Signals — set short/long SMA windows, inspect both overlays and select a confirmed event by date, direction and values. The chart pins and marks the candle and the summary follows it.
- [x] Top-right Paper trading / Trade — show simulation rules, cash and holdings. Submit buy/sell/close/hold/wait with quantity and retry safely. Retain order status, reasons, timestamps, fills and observation provenance. Show average cost, realized/unrealized/total P&L, valuation source/time and historical ledger.
- [x] Top-right Paper trading / Automation — preserve live-only start/stop, stopped/pending/error states, snapshot and chart preview, checks for eligible quotes, cancellation, veto or skip reasons, and the complete attempt-to-fill audit with resulting balances. Keep Stop reachable while active.
- [x] AI summary and decision proposal — freeze a completed candle with account and indicator facts. Retain snapshot identity, source, cutoff, eligibility, chart preview and questions. Request a proposal or image analysis and inspect validation, reviewer output, errors and the saved capture. Manual analysis sends no order.
- [x] Voice chat — discuss the new analysis or choose another saved decision. Inspect validation, review and simulated outcomes. Start/end voice, ask follow-ups, check microphone and session status, handle denial or disconnect, and access audio and captions.
- [x] Shell — wordmark, diamond tab icon, installed app icon, standalone manifest and Apple home-screen icon. A keyboard-accessible chevron collapses the rail. On phones the controls collapse above the chart.
- [x] Switching tabs or opening Paper trading preserves the selected candle, chart context, active automation, in-flight proposal and voice session. Browser tests checked a pinned candle, the proposal-to-voice link and capture, a running paper bot and a connected synthetic-microphone session.
- [x] Run the existing workstation SmokeTest and feature-specific replay, indicator, paper, review, automation and voice checks as appropriate; exercise each destination through the new navigation. Distinguish fixture results from live-provider and microphone checks. Preserve backend APIs, recording/persistence and existing documented non-UI workflows.
