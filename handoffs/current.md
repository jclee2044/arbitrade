## Latest feature task: realized/unrealized P&L history

User asked to continue attached Prompt 9D. Preserved unchanged attachment as
prompts/16-record-profit-and-loss.md, retaining all prior files.

backend/pnl.py implements exact weighted-average purchase cost, cumulative
realized, unrealized and total P&L. Buys add purchase cost; sales realize
quantity × (fill price − average cost); remaining shares keep their average.
Fractions preserve recurring costs, while readable USD text columns use up to
40 significant digits and Vue displays two fractional digits. Flat quantity
has zero unrealized and retained realized total. Missing open valuation is NULL
and displayed Unavailable, not zero.

Two additive tables in existing chart-config.sqlite3: paper_pnl_state holds
exact cost/realized and durable mark state; paper_pnl_history retains account,
symbol, stable event, event/price times/source/price, cash/shares/average cost,
realized/unrealized/total, exact values and fill/candle/receipt references.
Fill P&L is atomic with fill/balances/order/cursor. Old fills backfill once at
startup without changing original records or inventing historical candle marks.

Open positions are valued by completed regular-session **1m** closes, independent
of selected chart timeframe. Newly completed valuations apply to prior holdings
before that receipt's fills. Bars ending at/before latest fill can't value
later holdings. Latest-bar changed close appends a new version; older events
cannot rewind it and repeat events add no entry. Earlier rows remain available
through updates/close. Flat positions receive no new candle marks.

Live history uses available time plus explicit receipt-ID boundary, including
tied timestamps. Replay uses only its revealed in-memory observations/recorded
clock. Future receipts wait for clock. Optional PaperBroker clock injection is
for deterministic fixtures; production uses actual UTC. Account API now includes
pnl_history and pnl_summary. Vue shows current figures, source/time and retained
student-readable table; mobile history scrolls horizontally.
